# 发票勾选保留修复与回归记录

日期：2026-09-24。

## 原因与修复

取消最低金额筛选会替换列表数据。原实现监听通用 selection-change 事件，表格内部自动清空勾选时，会把空集合传给 syncVisibleSelection，从全局集合删除当前页的已选发票。渲染后的恢复监听器再执行时，选择已经丢失。

修复将写入入口改为用户操作产生的 select 和 select-all。单行事件仅更新对应 ID；全选事件仅同步当前页；数据刷新后的回填只从全局集合读取。移除不再需要的异步同步标记，不改变后端、筛选参数、布局或生产依赖。

## 回归检查

1. 修复前精确基线重现取消最低金额后的选择丢失。
2. 最低金额筛选后勾选两张发票。
3. 清空最低金额后，保留当前页和其他页的已选发票。
4. 翻到第二页，正确恢复原先不可见的勾选。
5. 跨页新增选择并返回第一页。
6. 当前页全选，不丢失其他页的选择。
7. 当前页取消全选，仅取消当前页选择。
8. 筛选结果为空，保留选择。
9. 空结果后清空搜索，保留选择。
10. 用户主动取消单行，仅移除该发票。
11. 点击列表刷新，保留选择并使用新行对象。
12. 每页条数切换到 50，保留选择。
13. 展开更多筛选，保留选择。
14. 每页条数恢复到 20，保留其他页选择。
15. 点击清空搜索，保留选择。
16. 打包下载将全局已选 ID 传入模拟 API，包括不在当前页的发票；不生成真实 ZIP。
17. 从列表进入批量打印，全局选择保持一致。
18. 批量打印显示的已选数量与全局集合一致。
19. 返回列表并翻页，恢复对应复选框。
20. 用户确认清空选择，集合及复选框正常清空。
